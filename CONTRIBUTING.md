# Contributing

This is a solo portfolio project. No external contributions expected, but the structure is here for completeness.

If you find a bug or have a suggestion, open an issue.

## Local setup

See the README for full setup instructions.

## Code style

- Python: `ruff` for lint and format. Run `make lint` and `make format`.
- Type annotations required on all public functions. Run `make typecheck`.
- Tests: `make test` for unit, `make test-int` for integration.
